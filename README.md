# 생산 지수 시뮬레이터

첨부된 농장주 PI 화면을 바탕으로 만든 모바일용 계산기입니다. PI 계산만 제공합니다.

- 현재 PI: (육성률 × 평체) ÷ (사육일령 × FCR) × 100
- 목표 PI에 필요한 평체·FCR·사육일령·육성률을 각각 역산합니다. 다른 세 항목은 고정합니다.
- 필요한 값을 누르면 해당 조건의 PI를 확인하고 저장할 수 있습니다. 다시 누르면 현재 조건으로 돌아옵니다.
- 목표를 충족하도록 평체(0.001kg)·육성률(0.01%p)은 올림, FCR(0.001)·일령(0.01일)은 내림합니다.
- 예시: 98.9%, 1.75kg, 31.3일, FCR 1.45 → 현재 PI 381.3.
- 목표 400: 평체 1.836kg 이상 / FCR 1.382 이하 / 일령 29.84일 이하. 육성률만으로는 100%를 초과하여 불가능합니다.

## 기록

입력값, 목표 PI, 계산 결과, 저장 시각을 최근 50개까지 이 브라우저의 localStorage에 저장합니다. 조정 항목을 선택했다면 조정된 값을 저장합니다. 기록을 누르면 해당 값과 목표를 불러옵니다.

DB·로그인·가상 사용자 ID는 사용하지 않습니다. 기록은 서버로 전송되지 않고 기기·브라우저·사이트 주소 간 공유되지 않습니다. 브라우저 데이터를 삭제하면 기록도 삭제됩니다. 시각은 기기의 현지 시간으로 표시합니다.

## 개발 및 검증

Node.js 24 LTS를 사용합니다.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

기본 포트는 개발 5173, 빌드 미리보기 4173입니다. 결과물은 dist/입니다.

## Vercel 배포

1. 변경 사항을 GitHub에 반영합니다.
2. Vercel에서 Add New → Project로 seongjiny/mini-apps를 가져옵니다.
3. Root Directory는 저장소 루트, Framework Preset은 Vite로 지정합니다.
4. Deploy를 누릅니다.

vercel.json에 npm ci / npm run build / dist 설정을 포함했습니다. 환경변수와 DB 설정은 필요하지 않습니다. 로컬 빌드 검증과 실제 Vercel 배포는 별개입니다.
